# Хакатон по индустриальной биостатистике

**Проспективное, многоцентровое, рандомизированное, тройное слепое, клиническое исследование с активным контролем в параллельных группах по сравнительной оценке эффективности и безопасности препарата Траумель, гель для местного применения, по сравнению с гелем диклофенака 1% при лечении боли у пациентов с остеоартрозом коленных суставов**

Репозиорий содержит:

1. Синопсис из протокола исследования (`Синопсис.docx`)
2. Раздел протокола "Статистическая обработка данных" (`Протокол.docx`)
3. Статистический отчёт исследования (`Отчёт.docx`, `Отчёт.Rmd`)
4. Данные пациентов (директория `data`)
